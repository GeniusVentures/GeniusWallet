## Fixture spec (offline seeded data)

All coins carry a real `iconPath`, `balance`, `symbol`, `name`; each has a matching `CoinGeckoMarketData` (keyed by **lowercase symbol**) supplying `currentPrice` + `priceChangePercentage24h`. `CoinCardRow` computes value = `currentPrice * balance` and gain/loss = value * (change% / 100); positive change renders green (`colorScheme.primary`), negative renders red (`colorScheme.error`). Total balance = sum(value), formatted `toStringAsFixed(2)` as a plain number string (matches develop's `_calculateTotalValue`).

**Scenario A — Populated** (mixed +/- with BOTH a green gainer and a red loser):
- ETH — name "Ethereum", iconPath `assets/images/crypto/eth.png`, balance `1.35`, price `3200.00`, change `+3.20` (GREEN gainer)
- BTC — name "Bitcoin", iconPath `assets/images/crypto/btc.png`, balance `0.042`, price `64000.00`, change `+1.10`
- USDC — name "USD Coin", iconPath `assets/images/crypto/usdc.png`, balance `250`, price `1.00`, change `+0.02`
- GNUS — name "Genius", iconPath `assets/images/crypto/gnus.png`, balance `1200`, price `0.85`, change `-5.40` (RED loser)

**Scenario B — Long / extreme values** (stresses row overflow + AutoSizeText per 05-03 criterion 5):
- MEGALONGSYM — name "Megatoken Ultra Long Display Name Coin", iconPath `assets/images/crypto/agi.png`, balance `123456789.123456789`, price `0.000000012345`, change `+12.34`
- WHL — name "Whale", iconPath `assets/images/crypto/sol.png`, balance `9876543.21`, price `123456.78`, change `-8.90`

**Scenario C — Missing-icon** (exercises the `image_not_supported` fallback in `buildTokenIcon`):
- NOICON — name "No Icon Coin", iconPath `''` (empty), balance `42.5`, price `12.34`, change `+2.10`

**Scenario D — Clear**: mock-mode OFF, wipe coins + market data, return to real (empty) wallet state.

  <action>
CUBIT (`wallet_details_cubit.dart`):
- Add a plain field `bool mockMode = false;` (dev switch; contains no fixtures — fixtures stay in lib/dev).
- Add `void injectMockCoins(List<Coin> coins, {required String balance})`: sets `mockMode = true` then emits `state.copyWith(coinsStatus: WalletStatus.successful, coins: coins, selectedWalletBalance: balance)`.
- Add `void clearMock()`: sets `mockMode = false`, emits `state.copyWith(coinsStatus: WalletStatus.successful, coins: const [], selectedWalletBalance: '0')`, then calls `getCoins()` so the real (empty) live path resumes.
- At the very top of `getCoins()` (before the loading emit), early-return when `mockMode` is true so the live read cannot overwrite the mock. Guard it as `if (mockMode) return;`. (This also neutralizes the `selectNetwork`/`selectWallet` re-fetches while mock-mode is ON.)

COINSCREEN (`coins_screen.dart`):
- Import `DevMockHoldings` and `kDebugMode` (package:flutter/foundation.dart).
- At the very top of `_fetchMarketData`, before the `_isFetchingMarketData`/`coins.isEmpty` guards, short-circuit while mock-mode is ON: `if (kDebugMode && context.read<WalletDetailsCubit>().mockMode) { setState(() { _marketData = DevMockHoldings.instance.marketData; _isFetchingMarketData = false; }); return; }`. This makes the 1-min refresh timer and the BlocListener's `successful`-branch fetch both no-op the network while feeding rows the seeded offline prices, and it skips `_calculateTotalValue` (the balance is already set by `injectMockCoins`).
- Do NOT touch the real path otherwise: when `mockMode` is false every existing branch (loading surface, `GWEmptyState`, live fetch, `_calculateTotalValue`, token-info push marketData) stays exactly as-is.
