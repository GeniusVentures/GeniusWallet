# 260721-ch1 — Markets header: "View all" editorial link

## Objective

The Markets panel header's trailing slot currently shows dead metadata filler
(`Text('Top ${n} · 24h')`). Replace it with the approved **variant D — Editorial**
from `.planning/sketches/003-markets-panel/view-all.html`: a boxless, right-aligned
uppercase "VIEW ALL" text link with a trailing arrow that navigates to the full
`/markets` page, with a desktop hover state (brand tint + arrow slide + gradient
underline draw).

## Design contract (locked, mockup D)

- Label "VIEW ALL" uppercase, ~11px, `w600`, tracked (letterSpacing 0.08em ≈ 0.88),
  color `gw.textSecondary` at rest.
- Trailing right-arrow (`Icons.arrow_right_alt`, ~15px), same color as label.
- Hover (desktop): label + arrow → `brandPrimary`; arrow slides ~3px right; a thin
  (1.5px) `brandCta` gradient underline draws under the LABEL width only (not the
  arrow). Pointer cursor.
- No background box (lightest footprint). Right-aligned in the `GWSectionTitle`
  trailing slot.
- onTap → `context.go('/markets')` (`/markets` is a top-nav shell destination — `go`
  switches the shell tab, not `push`).

## Approach (LAZY)

1. **New reusable widget** `lib/components/cards/gw_view_all_link.dart` —
   `GWViewAllLink({required VoidCallback onTap, String label = 'View all'})`.
   Hover needs mutable state → small `StatefulWidget` + `MouseRegion`
   (`onEnter`/`onExit` → `setState`) + `GestureDetector` (NOT `InkWell`, which
   paints a hover/splash box the design forbids). Implicit animations
   (`AnimatedOpacity` for the underline draw, `AnimatedContainer` transform for the
   arrow slide) at `GeniusWalletMotion.base` (200ms, the design-locked duration;
   `fast` is 120ms). Fail-soft `gw` read for live appearance re-skin.
   - Underline sized to label width via a `Column(crossAxisAlignment: stretch)` with
     the arrow OUTSIDE the column; slot always reserved (3px gap + 1.5px bar, opacity
     animated) so hover never shifts row height/baseline.
2. **Wire** into `dashboard_markets.dart`:
   `trailing: GWViewAllLink(onTap: () => context.go('/markets'))`. Remove the old
   `Text` + the now-unused `GeniusWalletTypography` import (`gw` stays — still used
   for `gw.borderSubtle`; `visibleCoins` stays — still used for the list).
