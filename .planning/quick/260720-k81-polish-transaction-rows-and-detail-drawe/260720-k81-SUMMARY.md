# Quick Task 260720-k81: Polish Transaction Rows and Detail Drawer Summary

**Four re-skin/layout fixes closing the 05-06 transactions walk feedback: white badge border+arrow on-fill, row spacing so card shadows clear, plain (uncarded) detail-drawer data rows across all three drawer variants, and an un-clipped drawer top close button — no behavior change.**

## Accomplishments

- **Badge on-fill (transaction_displays.dart):** `_buildCoinIconWithBadge`'s `Border.all(color: ...)` and `Icon(color: ...)` changed from `GeniusWalletColors.textOnBrand` to `Colors.white`. Fill (`bgColor` param — lightBlueAccent/brandGreen/statusError) and border width (1.5) untouched.
- **Detail-drawer card removed (transaction_displays.dart):** `_buildDetailsCard` no longer wraps rows in a `Container` + `GWDecorations.surface` (fill/border/shadow). Returns `Padding(vertical: GeniusWalletConsts.space2, child: Column(spacing: 10.0, children: rows))` directly on the drawer surface. This single helper feeds all three drawer variants (Send/Receive `TransactionItem`, Buy `TransactionPurchasedItem`, Swap `TransactionSwappedItem`), so one change fixes all of them.
- **Row spacing (transactions_slim_view.dart):** `ListView.builder` → `ListView.separated` with `separatorBuilder` giving 12px (`GeniusWalletConsts.space6`) gaps between rows, plus list `padding: EdgeInsets.symmetric(vertical: space6, horizontal: space2)` so shadows aren't clipped by the ListView's own hard edge. Added the `genius_wallet_consts.dart` import. This list also feeds the dashboard transactions card, so the fix applies there too.
- **Drawer close button + corner radius (responsive_drawer.dart):** the AppBar's `leading` close `IconButton` is now wrapped in `Padding(left/top: space2)` with `leadingWidth: 56` on the AppBar, insetting it clear of the rounded top-left corner. Both raw `Radius.circular(28)` literals (desktop panel left corners, mobile bottom-sheet top corners) tokenized to `GeniusWalletConsts.radius3xl` (24). Added the `genius_wallet_consts.dart` import.
