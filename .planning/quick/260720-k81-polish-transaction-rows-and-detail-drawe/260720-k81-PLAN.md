(B) DRAWER TOP BUTTON CLIP — `responsive_drawer.dart`. The AppBar `leading` close `IconButton` (~:124-127) sits flush in the top-left corner, which the drawer rounds at radius 28 (desktop Container left corners at :56; mobile bottom-sheet top corners at :81) with `Clip.antiAlias` — so the close glyph is bitten by the corner. Apply a MINIMAL fix, preferred over broadly changing the shared radius: inset the close button clear of the corner. Wrap the leading `IconButton` in `Padding(padding: EdgeInsets.only(left: GeniusWalletConsts.space2, top: GeniusWalletConsts.space2), child: ...)` and set the AppBar's `leadingWidth` so the padded button isn't cramped (e.g. `leadingWidth: 56`). BLAST RADIUS — state in the SUMMARY: this file is the shared drawer used by EVERY `ResponsiveDrawer.show(...)` caller (transaction detail drawers plus any other consumers), so the inset + 28→24 corner change is visible in all of them. The change is conservative (rounded corners preserved, only slightly tighter; close button simply inset) and behavior-neutral.
