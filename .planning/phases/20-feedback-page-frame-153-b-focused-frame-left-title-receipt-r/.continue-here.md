## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---|---|---|---|
| Borderless field grows a box on focus | `theme.dart:242` sets an app-wide `focusedBorder`. `InputDecoration.border` is only the FALLBACK, and a per-state border always beats it — so a field declaring `border: InputBorder.none` still grew a flat blue box the moment it took focus. | advisory | Any field claiming to be borderless must silence **all four** states (`border`, `enabled`, `focused`, `disabled`), not just `border`. |
| Hover that moves the content | An `AnimatedContainer` animating from a decoration with **no** border to one **with** a 1px border twitches its child: a `BoxDecoration` carrying a border insets its child by the border width. | advisory | Keep the border present in both states and change only its colour (transparent when idle). The nav tabs carry the same latent bug. |
| `textAlign: center` doing nothing | A `Stack` gives non-positioned children **loose** constraints, so a `Text` inside one shrink-wraps and has no box to centre within. Every label sat flush left while the underline spanned the full segment. | advisory | Wrap in `SizedBox(width: double.infinity)`, and assert centring against the label's **own segment**, not a computed fraction. |
| Rounding a value that is also an input | `formattedBalance` renders full token precision (`0.010000000000000221`), but MAX feeds that exact string into the amount field. Rounding it for readability would strand dust or over-ask. | blocking | Add a separate display-only getter; never round a value that doubles as an input. |
