- `GnusJobStore.app()` over `Hive.box<String>(gnusJobsBoxName)`; the only place outside `lib/hive/` naming the box.
- `byJobId(jobId)`: exact match on a non-null jobId (null until SDK-JOBID).
- `byIdempotencyKey(origin, key, {notBefore})`: newest record with exact origin and key, `submittedAt` not before `notBefore`.
- `page({sdkAddress, limit, cursor})` -> `(jobs, nextCursor)`: same lowercased `sdkAddress`, order `submittedAt` desc then lowercased `burnTxHash` desc, strictly after the cursor; `nextCursor` only when more remain; `FormatException` for an undecodable cursor.
- Cursor: `base64Url` of UTF-8 `<submittedAt micros>|<lowercased burnTxHash>`.
- Lookups scan decoded `box.values`; a value failing `GnusJob.decode` is skipped and counted in one `debugPrint` (count only). Mark the scan `// ponytail:` linear, fine to a few thousand jobs; upgrade is a secondary index per origin and key.
- `cache.dart`: `const String gnusJobsBoxName = 'gnusJobs';`

Handler: `gnus_listJobs` `{limit?, cursor?}` -> `{jobs, nextCursor}`; `gnus_getJob` exactly one of `{jobId}`, `{burnTxHash}`, `{idempotencyKey}` -> Job map plus `result: null`, or `null`; a private in-flight state (bool plus the `origin|idempotencyKey`).
