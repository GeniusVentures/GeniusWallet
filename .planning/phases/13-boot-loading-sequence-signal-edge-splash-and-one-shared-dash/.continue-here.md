## Boot screen — trust the code, not the sketch

```dart
const Color  _kBootCanvas        = Color(0xFF06070B);
const double _kBootMeshIntensity = 0.40;
const int    _kBootMeshDim       = 235;   // NOT sketch 020's 120
```

**Sketch 020's numbers are wrong.** Its CSS blobs were far more contained than `_MeshPainter`'s
(radius `maxDim * 0.95`, fills the whole rect), so the mock rendered much darker than the app at
identical values — every variant understates real brightness. `dimAlpha: 235` was settled on the
live app. **Trust `splash.dart` over that sketch.**

Note `intensity` alone cannot darken this background: in `_MeshPainter` it scales the blob alpha
(`110 ×`) **and** the black overlay (`38 ×`) together, so lowering it yields a paler field, not a
deeper one. That is why `dimAlpha` exists.
