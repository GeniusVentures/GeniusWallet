<objective>
Remove the measurement instrument, then walk the whole phase as one thing.

Purpose: the four earlier plans each verified their own slice — 13-01 read the console, 13-03 walked the boot
screen, 13-04 walked dashboard entry. None of them walked a cold start END TO END, and one of this phase's
five success criteria has not been exercised at all yet: opening the app with the network unreachable
(SC3, M5). 13-02 bounded the CoinGecko requests and 13-04 deleted the loaders that used to cover for them,
but the combination — no network, no loaders, a bounded fetch falling back to a Hive cache, and a boot
screen that must still hand over — has never been run.

`rgba(255,255,255,.38)` is the weakest pair on the screen and it sits over a tinting, drifting mesh; 13-03
looked at it, and this plan confirms it survived everything landed since. `GWMeshBackground`'s ~27%
single-frame jump on resume (H3) was predicted to be masked by the handover and had never been observed
before 13-03; if 13-03 saw it, this is where the phase decides whether it ships or becomes a follow-up.

The cleanup is small and deliberate. 13-01's `[boot-timing]` print existed to answer 13-RESEARCH's open
question 1 and named this plan as its removal point in its own comment. Its answer is recorded in
13-01-SUMMARY.md and is already baked into 13-03's coins-leg decision. Leaving the print behind would be
keeping scaffolding after the building stands.

Output: a clean boot path, and a phase closed on observation rather than on inference.
</objective>
