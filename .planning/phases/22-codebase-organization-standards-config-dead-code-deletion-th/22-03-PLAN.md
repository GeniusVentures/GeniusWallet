<objective>
Nine hand-written production widgets under `lib/components/` are named `*.g.dart`. That suffix means
"generated" to every Dart tool, and `analysis_options.yaml:5` excludes `lib/**/*.g.dart` — so the
analyzer, and therefore every lint rule and every CI gate this phase adds, is completely blind to
them. Renaming them is what makes the rest of Phase 22 apply to the whole codebase instead of most
of it.

This is more delicate than a file rename. These nine files are a deliberately-preserved shadow set
from Phase 03, one of them (`WalletsOverview`) shadows a live class name, and two artifacts in
`tool/` pin their exact paths as part of an existing security gate. All of that moves with them.

Purpose: end the analyzer blind spot without breaking the guard that documents why the blind spot
was tolerated.
Output: 9 renamed files, updated importers, updated boundary gate, and a recorded new analyzer
ceiling.
</objective>
