**THE BLOCKER for resuming — read this before doing anything else.**

`06-02`'s walk needs a genuinely wallet-less profile, and so does `06-03`. The app persists a wallet across **four independent stores** (see `.planning/todos/pending/2026-07-21-four-independent-wallet-persistence-layers-with-no-documente.md`):

1. Hive boxes (`.hive`/`.lock` files)
2. Native SuperGNUSNode directory (RocksDB node identity)
3. `flutter_secure_storage` v9's Windows FILE — **the one that matters** (seeds, keys, PIN); NOT the Credential Manager, despite that being the first (wrong) hypothesis chased today
4. `shared_preferences.json`

Getting one fresh install today took **four attempts**, consumed by a single walking session because completing onboarding recreates the wallet.

**RESOLVED 2026-07-22. `GW_DATA_DIR` is REJECTED — do not build it, do not propose it again.** The accepted answer is the documented procedure in **`.planning/reference/FRESH-INSTALL-RECIPE.md`**, verified by direct measurement. Use that document, not the abbreviated list below, which is kept only because it is quoted in older notes and is wrong in two places (`shared_preferences.json` does not exist for this app on Windows; a ~310-byte `flutter_secure_storage.dat` is normal on a fresh profile).

**Accepted cost of that decision:** every walk that completes onboarding consumes the profile, so the recipe re-runs per walk. Known and accepted, not overlooked.

**Manual fresh-install recipe (superseded by the doc above — see it first):**
1. Close the app (single-process Hive lock).
2. Delete `%USERPROFILE%\Documents\*.hive` and `*.lock`.
3. Delete `%USERPROFILE%\Documents\SuperGNUSNode.Node.*` (native RocksDB node identity).
4. Delete `%APPDATA%\com.example\genius_wallet\` — **this is the one that matters**: seeds, keys, PIN. `flutter_secure_storage` v9 on Windows uses a FILE here, NOT the Credential Manager.
5. Also delete `Documents\overrides\` and the five `*_config.json`.

Do NOT delete anything from Windows Credential Manager — that was today's wrong hypothesis and cost 13 unrelated `SGNUS*` entries irreversibly.
