<objective>
Re-skin the two webview hosts — the payment webview GAP-05 names as `banxa_payment.dart`, and the
KYC registration screen.

These two files are near-identical twins: both branch on `Platform.isLinux`, both fall back to the
system browser, and both render the same shape of fallback screen. 09-RESEARCH groups them into
one unit because the copy-paste value of doing them together is high and because a divergent pair
here would be an obvious seam.

Neither file contains a single raw colour literal today. Their re-skin is structural: a shared
AppBar, an icon-in-circle fallback layout, and two button swaps. What matters most in this plan is
what is NOT touched — `kyc_registration.dart` holds the redirect-matching logic that is the phase's
flagged blocker (finding 1), and D-02 fences it out.

Purpose: close `banxa_payment.dart`'s share of GAP-05 and bring both fallback screens onto the
shipped empty-state recipe, while leaving the redirect logic provably untouched.
Output: both files re-skinned in place, one widget test rendering both fallback screens, and a
diff gate proving the navigation-delegate bodies are unchanged.
</objective>
