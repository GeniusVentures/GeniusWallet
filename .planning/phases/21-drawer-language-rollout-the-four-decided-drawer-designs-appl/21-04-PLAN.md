<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| remote dApp -> drawer identity | `dappName`, `dappUrl`, `dappDescription` and `iconUrl` all come from the connected peer's session metadata. The peer is untrusted by definition. |
| dApp -> transaction parameters | `to`, `from`, `value`, `gas`, `maxFeePerGas`, `maxPriorityFeePerGas` arrive in the session request and are formatted upstream in `handle_dapp_requests.dart`. |
| drawer -> signing decision | The drawer's `Future<bool?>` is the sole input to whether the wallet signs. |
| `iconUrl` -> `Image.network` | An attacker-supplied URL is fetched by the wallet when a signing prompt opens. |
| address value -> clipboard | `GWCopyRow` writes the recipient address to the system clipboard on tap. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
