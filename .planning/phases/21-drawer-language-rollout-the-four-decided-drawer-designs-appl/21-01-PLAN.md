<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| model string -> drawer row | Wallet names, token names/symbols and network names originate in remote or user-controlled data and are rendered as text inside a fixed-width panel. |
| remote URL -> row leading slot | `GWDrawerListRow`'s `leading` slot will carry `Image.network` for token logos in the converted callers. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-21-01 | Denial of Service | `GWDrawerDetailRow` value text | medium | mitigate | Value text keeps `maxLines: 1` + `TextOverflow.ellipsis` as a pair, carried over from `_buildRow`'s T-12-02 guard. An unbounded model string cannot grow the row. Asserted in Task 2's acceptance criteria. |
| T-21-02 | Denial of Service | `GWDrawerListRow` title/subtitle | medium | mitigate | Both ellipsize at one line. A long wallet name or token name cannot overflow or unbound the row height. |
| T-21-03 | Information Disclosure | `GWDrawerListRow` leading `Image.network` | low | accept | The primitive does not fetch anything itself; the caller supplies the widget. Fetch behaviour is unchanged from `_TokenRow`, which already ran one fetch per visible row in this same list. This plan neither adds nor removes a network call. |
| T-21-04 | Tampering | `ResponsiveDrawer.show` signature | low | mitigate | The new parameter is additive with a default that preserves every existing caller's behaviour byte-for-byte; Task 1's third test case asserts exactly that. No existing named argument changes meaning. |

No package-manager installs in this plan. No new dependency of any kind.
</threat_model>
