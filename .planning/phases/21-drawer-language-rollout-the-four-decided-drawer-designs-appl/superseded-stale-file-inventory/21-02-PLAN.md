<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| chain/network metadata -> picker row | Network names, symbols and icon paths come from the network provider and from remote bridge metadata. |
| wallet model -> account row | Wallet names are user-supplied and addresses are model data, both rendered in a fixed-width panel. |
| row tap -> caller state write | Each picker's tap performs a state write, a cubit call and in two cases a Hive persist. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-21-05 | Denial of Service | picker row title/subtitle | medium | mitigate | Inherited from `GWDrawerListRow`, which ellipsizes both at one line (asserted in 21-01 Task 2). A long wallet name or an adversarial network name cannot overflow or unbound a row. |
| T-21-06 | Tampering | selection -> `walletCubit.selectWallet` / `selectNetwork` / `toNetwork` | high | mitigate | No selection path is edited. Acceptance criteria grep for each cubit call, each Hive write and the bridge `setState` still being present, so a chrome edit that silently drops a state write fails the task. |
| T-21-07 | Spoofing | selected-row indication | medium | mitigate | Today the network picker shows NO selected state at all, so a user cannot tell which chain is active from the picker. The shared row's gradient check closes that. This plan improves the property rather than risking it. |
| T-21-08 | Information Disclosure | wallet address in the account row subtitle | low | accept | The address is already rendered in this row today via `SelectableText`. Moving it into the shared subtitle slot changes presentation only; no new data is exposed. |

No package-manager installs in this plan.
</threat_model>
