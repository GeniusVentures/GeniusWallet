<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| `Transaction` model -> receipt rows | `hash`, `recipients`, `fromAddress`, `coinSymbol`, `exchangeRate` and the swap quartet are chain-sourced and attacker-influenced; all are rendered as text in a fixed-width panel. |
| `coinSymbol` -> coin art asset path | `_identity` resolves an asset path from a symbol. |
| `explorerUrl` -> external browser launch | The footer button opens a URL derived from `coinSymbol` and `hash`. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-21-09 | Denial of Service | receipt detail rows | high | mitigate | Every row goes through `GWDrawerDetailRow`, which keeps `_buildRow`'s `maxLines: 1` + `TextOverflow.ellipsis` pair (T-12-02). An unbounded `exchangeRate` or address string cannot grow the drawer. Asserted in 21-01 Task 2 and re-asserted here by the analyze-clean requirement that no raw `Text` replaces a detail row. |
| T-21-10 | Tampering | `_coinImage` asset path from `coinSymbol` | high | mitigate | The plan forbids touching `_identity` or `_coinImage`. `iconSymbols` arrives pre-sanitised by 12-02's `sanitizeCoinAsset`; the receipt continues to use `content.iconSymbols` and never re-derives a path from raw `tx.coinSymbol` (T-12-01). |
| T-21-11 | Tampering | explorer URL launch | high | mitigate | The `Uri.tryParse` plus `scheme.startsWith('http')` guard and the `explorerUrl.isEmpty` suppression are both named in the acceptance criteria as must-survive. The restructure moves no part of the footer's logic. |
| T-21-12 | Spoofing | status presentation | medium | mitigate | The pill and the Status row are required to read their palette from ONE switch, so a future edit cannot make them disagree about a state. Today `pending` renders uncoloured, which under-states an unsettled transaction; this plan closes that. |
| T-21-13 | Information Disclosure | fiat line | low | accept | `valueLine` is already rendered on the resting row for the same transaction. Showing it in the receipt exposes nothing new; a null price still prints nothing rather than a fabricated zero. |

No package-manager installs in this plan.
</threat_model>
