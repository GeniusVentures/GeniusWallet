<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| pub.dev → build | `google_fonts` is a new third-party dependency entering the dependency graph of a self-custody crypto wallet. |
| Hive box → app state | The new `preferences` box holds a user-controlled string read back at runtime. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-01 | Tampering | `google_fonts` pub dependency | medium | mitigate | Not slop: `google_fonts` is the Flutter team's own package (`flutter/packages`), already validated on the design branch, and pinned to `^6.2.1` rather than floating. It fetches font binaries over HTTPS from fonts.google.com and caches them; it touches no key material, no FFI surface, and no Hive box holding secrets. Task 1 commits `pubspec.lock` so the resolved version is reproducible. |
| T-02-02 | Tampering | `appearanceModeKey` value read in `GWAppearance.load()` | low | accept | The persisted value is compared against the literal `light` and anything else falls through to the dark default — an unparseable or attacker-written value degrades to the default, never to code execution. The box holds no secret and is written only by `setMode()`. |
| T-02-03 | Information Disclosure | `preferences` Hive box | low | accept | Stores a dark/light enum only. No seed, key, address, or PIN goes near this box; it is deliberately separate from `walletBoxName`. |
</threat_model>
