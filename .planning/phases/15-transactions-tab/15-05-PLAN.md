<objective>
Make `/transactions` a page instead of the dashboard panel in a bigger window.

Purpose: `transactions_screen.dart` is 26 lines and contains three of the ROADMAP's four defects at
once. It wraps the panel in `Center > Padding(all: 16)`, so the page inherits the panel's
`GeniusBreakpoints.medium` (768) cap — on a 2000px window that is a 736px column with ~630px dead
on each side — inherits the panel's 18px `GWSectionTitle` where every other full page uses the 24px
`GWPageHeader` (`markets_screen.dart:73`, `crypto_news_screen.dart:50`, `swap_screen.dart:228`),
and wraps it in nothing, so rows hang on raw `surface-base` while the dashboard wraps the identical
widget in `DashboardScrollContainer`.

15-04 built the page presentation behind a flag. This plan is the frame around it and the three
lines of plumbing that reach it.

Output: `transactions_screen.dart` rewritten to `markets_screen.dart`'s shape, a `page` pass-through
on both stream widgets, and a widget test on the frame itself.

Requirements covered: TT-01 (page frame).

NOTE: per `./CLAUDE.md` this repo's commit gate is held by the user. Do NOT create commits.
</objective>

Four things to comment, because each is a decision rather than a transcription:

1. **`xl` (1280), not `xxl`.** Markets caps at xxl because a coin grid genuinely uses 1536px by
   adding columns. A transaction list does not add columns — sketch 020's variant C, the wide
   table that would have, was rejected because it breaks Phase 12's just-locked one-anatomy rule.
   1280 is where the rail plus a row stops gaining anything.
2. **The `Padding` is OUTSIDE the `ConstrainedBox`, and that order is load-bearing.** A max-width
   only constrains when the viewport is WIDER than it, so at phone width the `ConstrainedBox` does
   nothing and the gutter must come from the `Padding`. This exact defect — CTAs glued to the
   window bezel at narrow width — was found by the 06-01 walk in `wallet_creation_screen.dart` and
   fixed the same way. Do not "simplify" the two into one.
3. **`GWPageHeader` owns its bottom gap**, so there is no `SizedBox` after it. Adding one is how
   this page would drift out of alignment with Markets and Swap.
4. **The 12/8 padding matches `markets_screen.dart:68` deliberately**, replacing the old
   `EdgeInsets.all(16)`. Two sibling tabs with different page gutters is the kind of difference
   nobody can name but everybody sees.

Add the two imports (`gw_page_header.dart`, `breakpoints.dart`) and remove nothing else — the
`WalletType` / `WalletDetailsCubit` imports are still needed by the branch.

**The panel title is now gone from this route** (15-04's `_page` emits no `GWSectionTitle`), so the
page has exactly one title, at 24px. If a second "Transactions" string appears on screen, the flag
did not reach the slim view — check Task 1's forwarding before touching anything else.
