into the 035-B unified omnibox toolbar (D-01/02/03): back+forward nested into the field's left edge,
favicon + secure lock + host in the middle, refresh at the right edge, `⋯` overflow menu outside the
field. Brand focus ring on focus; the field collapses to the host at rest and expands to the full
editable URL when focused. All navigation mechanics stay verbatim — this is chrome only (D-09).

match the redesigned chrome above it.

omnibox in `web_view_mobile.dart`.
