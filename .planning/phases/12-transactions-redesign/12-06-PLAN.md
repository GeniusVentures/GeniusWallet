the pure content derivation (12-02): token-first headline with a quiet action chip, a real

Launch on this machine (macOS — `flutter run -d windows` is wrong for this box):

    flutter run -d macos --dart-define=GW_DEV_TOOLS=true

1. Open the dev-tools bubble, MOCK section, press **Mock txns**. Go to the dashboard. The
   Transactions panel should now show the extended batch from 12-05.
2. Widen the window so the dashboard is in its multi-column layout and the Transactions panel is
   at its normal width. Stay in DARK for this checkpoint.
3. Walk the rows top to bottom and confirm, for EVERY row:
   - a coin icon with a badge in the corner — no row is a bare string in a box. The two that
     used to be exactly that are the **Processing job** row and the **Swapped** row; look at
     those two hardest.
   - a token headline, a quiet action chip beside it, one line of context beneath, an amount
     column and a time on the right.
4. Badges — check each glyph is legible against its own fill AT 18px, and that the ring around
   the badge is the panel surface colour, NOT white (a white ring is the `k81` regression that
   became 05-VERIFICATION's Gap 1):
   - Sent = slate, arrow out. Received = green, arrow in. **Mint = purple with a PICKAXE.**
     **Processing job = blue with a SERVER.** Escrow = slate lock. Pending = amber clock.
     Failed/cancelled = red cross.
   - The pickaxe is a hand-drawn SVG at 11px — say so if it reads as mush rather than a pickaxe.
5. The **long-value ETH row** (`123456789.123456789123456789`): it must read `123,456,789.12`
   and must NOT be what sets the panel's width. Hover it — a tooltip must show the exact
   full-precision value.
6. The **failed purchase** row: one em dash and one "Not charged". Confirm there is NOT a
   currency zero printed twice, which is what it did before.
7. `Fee:` must appear on NO resting row. Tap any row — the drawer opens and "Network Fee" is
   there, once.
8. Day separators: uppercase TODAY / YESTERDAY / a dated header, with a real clock time on each
   row. Confirm you do NOT see the same relative-time string repeated down the list.
9. Rows are separated by a straight full-bleed hairline — not by gaps between bordered cards, and
   never a rounded separator.
10. Named items from the executor summaries, judged deliberately:
    - the **swap row's identity**: both tokens visible in the 40px slot, badge anchored
      top-right (single-token rows anchor bottom-right). Does the asymmetry read as deliberate?
    - the **header rule** under the "Transactions" title: the Assets panel has no such line.
      Do the two panels still read as one system?
11. Compare the panel side by side with the Assets panel above/beside it: same 40px icon slot,
    same row padding, same hairline. If the two read as different systems, say where.

STOP and report if: any row lacks an icon or an amount column; any badge glyph is hard to read;
the long-value row still sets the panel width; the failed row prints a zero; `Fee:` survives on a
resting row; or the console shows any `RenderFlex overflowed`, exception or frame stall. Keep an
eye on the console for the whole checkpoint — this panel is in the column where `37639d5`'s
freeze lived, and a stall shows there first.
