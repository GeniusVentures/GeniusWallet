<risk>
**Freeze rule (phase-wide, from `37639d5`).** Every size in this plan is a fixed literal or a
4-pt token: 40, 24, 18, 44, 132, 16, 13. None is derived from `constraints`. Do NOT reach for
`AutoSizeText`, `FittedBox(fit: scaleDown)` or a `maxWidth * fraction` to solve an overflow here
— use `maxLines: 1` plus `overflow: ellipsis`, which is what every text in this row already
carries. The panel lives in the same height-starved dashboard column whose continuously-derived
font size froze the app.

**Second consumer.** `TransactionsSlimView` is mounted from THREE places, not two:
`lib/dashboard/home/view/dashboard_screen.dart` (via `TransactionsDashboardView` ->
`TransactionsStream`), `lib/dashboard/transactions/view/transactions_stream.dart`, and
`lib/dashboard/transactions/sgnus_transactions_screen.dart`. The full-page
`transactions_screen.dart` route renders the same widget with a 16px page padding, so any
regression shows on both the dashboard panel and the full page.
</risk>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| `Transaction` fields -> rendered row | Symbols, amounts, addresses and hashes are attacker-influenceable and reach text layout and an asset path |
| Row -> detail drawer | The drawer widens disclosure (full fee, hash, counterparty) on an explicit user tap |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-12-01 | Tampering | identity `Image.asset` path | medium | mitigate | The row consumes `content.iconSymbols`, already restricted to `a-z0-9` by 12-02's `sanitizeCoinAsset`; the row must not re-derive the path from `tx.coinSymbol`. `errorBuilder` falls back to the neutral dot |
| T-12-02 | Denial of service | row text layout | high | mitigate | Every `Text` carries `maxLines: 1` + `ellipsis`; the amount column is capped at a fixed 132; no size is constraint-derived; `NetworkImage` per row is removed so a scrolling list cannot fan out network fetches |
| T-12-04 | Repudiation | status presentation | high | mitigate | The row renders `content.badge` and `content.subtitle` verbatim from 12-02, whose per-status test is the gate. A failed row shows a dash plus "Not charged" and no currency zero |
| T-12-05 | Information disclosure | detail drawer | low | mitigate | Addresses and hashes stay truncated via `WalletUtils.getAddressForDisplay`; the drawer opens only on an explicit tap; the explorer button is suppressed when no explorer URL exists rather than opening an empty URI |
| T-12-SC | Tampering | package installs | low | accept | No install task in this plan |
</threat_model>
