## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Parallel executors | Two agents, one git index → cross-contaminated commits | blocking | Spawn one executor per wave, sequentially |
| Analyze-as-evidence | `flutter analyze lib` = 0 errors while 9 `.g.dart` files held 2 real compile errors | blocking | Canary import from a reachable entry point; human walk for render |
| Baselining a shadow | "Add it to the baseline" is the path of least resistance that turns the guard into theatre | blocking | Guard trip = STOP and report, never edit Check 2's baseline |
| Diffing the wrong branch | Orchestrator measured scope against `ui-redesign-3.514-develop` (an incomplete port) instead of `origin/ui-redesign-3.514` → undercounted 43 vs 60 | advisory | Always diff `develop..origin/ui-redesign-3.514` |
| Inheriting a count | Trusting a stated figure without re-running the diff let 2 files go silently unported | advisory | Reconcile file counts against the real diff every time |
