## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| dApp -> `event.method` / `event.params` | shape is unguaranteed: `params` is typed `dynamic` and `params[0]` is a Map for one method and a String for three others |
| wallet -> dApp JSON-RPC response | the dApp's only signal about what the user decided |
| approval decision -> Hive record | the persisted account of what was authorised |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-30-11 | Denial of service | unconditional `params[0]` Map cast | high | mitigate | Method is read and branched on before any shape-specific cast; a test pins that a String first param classifies without throwing for all three sign methods |
| T-30-12 | Repudiation | rejection response with a null (omitted) code | medium | mitigate | `Errors.getSdkError(Errors.USER_REJECTED)` supplies a real 5000; asserted by value, not by inspection |
| T-30-13 | Repudiation | signing failure reported as a user rejection | medium | mitigate | The failure site uses `JsonRpcError.serverError(...)`; only a real user rejection claims one |
| T-30-14 | Spoofing | undecodable calldata presented as a plain send | critical | mitigate | unknownCall renders an explicit warning and no send hero; a widget test asserts no "You send" row exists on that content |
| T-30-15 | Repudiation | Hive record claiming ETH for a token move | high | mitigate | The persisted symbol is taken from the same summary the drawer rendered, so the receipt cannot diverge from the screen |
