Design question: the transaction-detail drawer is the one panel every transaction type lands in (showTransactionDetails, transaction_displays.dart:430). Sketch 031 already decided how it should read - B1 · Pill + sections, inside the 030-B1 shell - and that decision was never ported. What shipped is a bare ListView with zero horizontal body padding: labels touch the left edge, values slam the right one. All five variants live inside the shipped drawer language (420px panel, 60px header, left title, ✕ top-right, gradient hairline, secondary = gradient outline) and use only fields txRowContent already computes on this exact call. A recommended every field is already in TxRowContent today: body padding = 0
