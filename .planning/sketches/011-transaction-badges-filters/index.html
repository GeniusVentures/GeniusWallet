1 · The badge colour question

These badges are filled circles with a knocked-out glyph, so the contrast that matters is glyph-against-fill, not fill-against-background. That is why saturated colours are safe here in both themes, while the same colours would fail as text. Each ratio below is the glyph on its own fill.

One hard constraint found in the code: statusWarning (#FFC42E) exists only as a static in genius_wallet_colors.dart:178 — it is not in the GWColors extension, so it is not appearance-aware. Fine as a badge fill; it would fail AA as text on white (1.7:1).
