Jakub, 2026-07-27: "buy genius - caly redesign tej strony - analiza co tam jest i tak dalej? jaki logic and so on". So this sketch is half analysis and half proposal. The analysis is first, because the single biggest problem here is not visual and no amount of re-skinning fixes it.

1 · The headline finding

routing The button labelled "Buy GNUS" does not open a buy screen. coins_screen.dart:349 pushes /buy; router.dart:80 maps /buy to OrdersPage - the order history. The screen that actually buys something is BanxaBuyScreen at /createOrder, and the only way to reach it is a small text action in the AppBar labelled "+ New Order". A user with no orders taps a gradient CTA that promises a purchase and lands on the words "Total Orders: 0 / No orders found." That is the screenshot.

5 · The constraint, and the way through it

Do-not-change vs redesign

CLAUDE.md says files under /banxa are auto-generated and must not be changed. The order list, the order card, the order details card, the KYC screen and the checkout screens all live there. Taken literally, none of the five variants above can be built.

They can all be built anyway, and cheaply, because the generated code is layered:

  • Models - banxa_model.dart: Order, Quote, FiatCurrency, Blockchain. Read-only, keep as is.
  • Service - banxa_api_services.dart. Keep as is.
  • Cubits - OrdersCubit, MakeOrderCubit, PollingCubit. Keep as is.
  • Widgets - banxa_orders_history.dart, order_card.dart, order_details_card.dart. These are the only files a redesign needs, and they are pure presentation over the cubits above.

So the redesign does not have to edit /banxa: it can add new widgets under lib/screens/ (where banxa_buy_screen.dart already lives, outside the fence) that subscribe to the same cubits, and repoint the routes in router.dart. The generated files stay byte-identical and simply stop being mounted. That is a routing change plus new files - zero edits inside the fence.

confirm Worth checking with Braian whether /banxa is genuinely regenerated by a tool, or whether the note is stale and the fence can be lifted for the three widget files. If it can, the same designs land with a smaller diff.
