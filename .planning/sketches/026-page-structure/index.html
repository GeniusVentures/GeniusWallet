026 · Transactions — whole-page structure

The real problem is not the tab's own header — it is that the navbar already says "Transactions" (active tab, underlined) and the page repeats it 24px below, floating under a full-width bar while the content is centred. Four whole-page structures. Each shows the shared navbar, because that is what the title has to relate to. Windows are 2000px scaled to fit.

Today baseline

Navbar names the page; page names it again; the 24px repeat then floats top-left of a centred block.

S1 · Drop the repeat — slim action toolbar page-local recommended

The navbar is the title. Remove the 24px "Transactions" entirely — the active tab already names the page, exactly like macOS Finder or a browser. In its place a slim contextual toolbar: actions right, and a quiet context line left (Showing all activity · 0x1d9b…4a87). Content rises ~90px. Touches only the Transactions page, not the shared navbar — the cheapest and least risky. Every other tab can adopt the same slim-toolbar pattern later, one at a time.

S2 · Full-width page-header band shared shell

A secondary bar under the navbar, edge to edge. The classic app shell: global nav → page header → content. Title left, actions right, spanning the FULL width (not capped), so nothing floats — then the cards below stay centred at 1600. Gives every page a consistent header strip. Cost: a new shared PageHeaderBar and a decision to apply it app-wide, so Markets/News/Swap all gain the band too.

S3 · Left sidebar navigation New shell milestone-size

Move the tabs from the top to a left rail. The top bar shrinks to logo + wallet cluster + Buy GNUS; navigation lives down the left. The page title then sits top-left of the content, properly aligned, and the sidebar eats the left width so a fullscreen window stops looking empty — the shell fills it by construction. This is the most "desktop app" answer and the one that truly fixes wide-screen emptiness. It is also a rewrite of the whole shell, affects every tab, and mobile keeps its bottom nav — a milestone, not a tweak.
