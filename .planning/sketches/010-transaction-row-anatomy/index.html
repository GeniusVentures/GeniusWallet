Transactions

8 transactions

What changed versus the shipped panel — the same in all three variants

  • One row skeleton for all seven types. "Completed job" and "Swapped" no longer render as bare strings in a box; they get the same identity, title, meta and amount columns as everything else. A swap shows both tokens in one identity instead of losing its icon.
  • Amounts are clamped, and the truth is preserved. 123456789.12345679 ETH becomes 123,456,789.12 with the exact value on hover — it can no longer set the panel's width. Tabular figures line the column up.
  • Fiat value on every row. A wallet's job is to say what something is worth; the shipped row only says how many tokens moved.
  • "Fee: 0.001 ETH" is gone from the resting row. It repeated on all eight rows and was never the reason anyone opened the panel — it belongs in the detail view.
  • Eight identical "a day ago" strings collapse into day separators with a net total per day, and a real timestamp per row.
  • Status shows only when it is not the happy path. Completed rows stay silent; pending pulses amber; failed reads red — and the failed row stops printing $0.00 twice.
  • Per-row cards become one surface with hairline separators, so the panel reads as a history rather than a stack of boxes.
