Rec my recommendation
On the pickaxe — one distinction worth making before you pick. A pickaxe reads as mining: doing work to earn. That is not what minting is — minting creates new tokens by decree, no work involved. But it is close to what a GNUS processing job does: spend compute, get value back. So the pickaxe probably belongs on Processing job, not on Mint. Both are offered in both places below so you can judge it rather than take my word.

Historically, "to mint" means to strike a coin with a die — which is why the stamp and hammer options are the literal metaphor, not a stretch.

1 · Mint icon New

Type TransactionType.mint — new GNUS tokens created into the wallet. Judge at 18px in the badge (top row of each card), not at the large size.

2 · Processing-job icon New

Type TransactionType.process — a GNUS compute job. The app's whole differentiator, so this icon carries more brand weight than the others.

3 · The Sent colour, without leaving Scheme 1

Scheme 1's rule is colour only where money moved. The catch you spotted: sending is money moving, so pure grey reads as "nothing happened". These five all keep Scheme 1's restraint — none of them shouts — but give Sent a temperature. Amber and red are deliberately absent: amber is already Pending and red is already Failed; reusing either would make a successful send look like a problem.
