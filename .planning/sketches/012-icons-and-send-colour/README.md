# Sketch 012: Mint / Job Icons + the Sent Colour

## Decisions
- **Sent = Slate `#64748B`**
- **Mint icon = Pickaxe**
- **Processing-job icon = Server**

## Why amber and red were excluded from Sent
Amber already means Pending and red already means Failed. Reusing either would make a *successful*
send look like a problem. Sending is a normal, successful action, not a warning.

## The pickaxe distinction (recorded because it cuts against the pick)
A pickaxe reads as **mining**: work performed to earn. That is *not* what minting is — minting
creates tokens by decree, no work involved — but it *is* close to what a GNUS processing job does.
The recommendation was therefore pickaxe-on-job; **Jakub chose pickaxe-on-mint and server-on-job.**
Recorded so the reasoning is not silently re-litigated later.

Historically "to mint" means to strike a coin with a die, which is why stamp and hammer were offered
as the literal metaphors.
