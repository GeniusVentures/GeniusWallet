182 - which four destinations belong on the bottom bar

Jakub, 2026-08-07: "zaproponuj jakie batony powinny byc na navigation bottom barze. Poki co mamy: home, markets, mamy ikone swap, activity i more. More bym zmienil na menu potencjalnie, i nie wiem czy bym zostawil markets i activity. Zasugeruj cos z twojej strony."

And then, later the same day: "sprobuj w prawym gornym rogu zrobic ikonke walletu, czy cos podobnego w krotszej formie, i obok tego hamburger menu. I wtedy, zamiast 'more' na samym dole, moglibysmy dac na przyklad 'news'." That second message changes the premise - if a hamburger moves into the header, the fourth bottom slot stops being a lid and becomes a fourth destination. Schemes S6 and S7 are that world.

This sketch is about which destinations, not about the bar. The shape is settled and shipped - sketch 171 B (four tabs plus a centre dock) crossed with 172 A (the dock is Swap), both picked on 2026-08-06 and live in responsive_overlay.dart. Every scheme below keeps four tabs and the Swap dock. What changes is which four. Tap the tabs - each phone really switches screen, so a set can be felt rather than read.
